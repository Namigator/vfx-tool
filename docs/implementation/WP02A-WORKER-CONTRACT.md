## Shared API
src/graph/signature.ts exports resolveSignature(node:NodeDefinition,spec:NodeSpec,context:{doc:EffectDocumentV2,graphId:string}):ValidationResult<ResolvedSignature>. ResolvedSignature = {nodeId:string,inputs:PortSpec[],outputs:PortSpec[],parameters:ParameterSpec[],disabledBehavior:NodeSpec['disabledBehavior'],bypass?:{input:string,output:string}}. It returns cloned metadata. Also export valueTypeToPortType(type:ValueType):PortType|undefined, checkPortCompatibility(source:PortSpec,target:PortSpec,fieldPath:string):Diagnostic[].
Number/integer map scalarSignal; booleans/colors/vec2/vec3/quaternion map corresponding signals; asset maps legacy asset (no implicit conversion to role-specific asset types). Other values have no signal port. Units exact (missing=none). Signal domains mandatory nonempty in registry; source domain set must be subset target, with constant always promotable to an allowed signal domain. Unknown/mismatched type blocks. Actual enum/string/curve/gradient/record values are not signal ports.
