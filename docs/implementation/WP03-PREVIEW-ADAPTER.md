The first visible v2 preview must be driven by actual saved graph data, not a copied v1 effect. Preserve current default v1 route. This is a limited F01/point-emitter preview and must visibly say so until the full renderer/catalog exists.

## Pure compiler adapter
Planned ownership src/graph/toParticles.ts/tests/v2-to-particles.test.ts. API compileParticlePreview(input:unknown):ValidationResult<ParticlePreviewPlan>, using production createRegistry -> analyzeGraph -> expandGroups. No DOM/Three imports. Type ParticlePreviewPlan has durationTicks, systems:{id,descriptor:ParticleEmitterDescriptor}[], layers:{nodeId,systemId,color:ColorValue,opacity,emission,blend:'normal'|'additive'|'cutout',alphaCutoff,renderOrderOffset}[], diagnostics through ValidationResult. Root transform applied to positions/velocity once; color combines InitialProperties.color and Material.tint in linear RGB then returns encoded sRGB/alpha (or expose explicit linear RGB values consistently). Renderer consumes plan/style, not arbitrary graph document.

Only reachable BillboardRenderer sinks at root EffectOutput.visual are lowered. Disabled sink contributes nothing. Empty expansion sources contribute no layer; empty elements filtered from multi lists. Traverse particles upstream through enabled InitialProperties to Emitter; disabled InitialProperties bypasses. Multiple billboards on identical terminal particle-chain ID share one simulation. Unknown reachable source/operator, dynamic signal input, exposed-control connection (until expression evaluation exists), unsupported shape/space/alignment/soft-intersection or unsupported changed appearance field returns an addressed error, never ignores settings or executes a fake fallback. Disabled Emitter returns no particles; disabled Material/Anchor acts absent and causes required-input diagnostic. Do not execute unused draft branches. Root audio/presentation connections must report not-yet-supported rather than silently vanish.

Map Emitter: document seed/duration, original emitterId/randomStreamId; anchorId resolves authored anchor, then root quaternion+scale+position transform; shape must point and space world; life seconds -> max(1,floor(seconds*60+.5)); lifetime min/max preserve order; equal speedMin/speedMax -> normalized direction times speed, transformed direction/scale. Differing speed range is unsupported until particle runtime supports it, must error. sizeMin/max from the last enabled InitialProperties or emitter defaults .08/.16, scaled by root scale. Initial rotation/angular motion currently particle runtime has no fields; only explicitly neutral values supported; F01 fixture must author rotationMin/Max/angularVelocityMin/Max =0 for honest rendering. color is appearance-only constant. Nonuniform scale unsupported here. This is an explicit scope restriction, not a hidden ignored value.

Triggers/window sources must be Schedule; Schedule.enabled=false emits no events. For burst, start/end outputs map to their respective tick; repeat mode adds repeatIntervalTicks for repeatCount, drops events at/after document duration. eventRandomKey uses scheduleEventRandomKey plus start/end tag if needed to distinguish same schedule event type. Runtime currently unique burst random keys; duplicate origins are an error until distinct event IDs are implemented. Rate can use one continuous Schedule window; repeat/multiple overlapping windows not supported by current descriptor. Window clamps to document end. Clock duration endpoint empties outputs. Point source requires a real anchor because Schedule supplies no event position, even if useEventPosition=true. Check required emitter trigger/window from graph, not just literal values.

No budget multiplication blind spot: aggregate simulation worst-case total births/live bound must not exceed plan15 cap; reject excessive bounded schedules/rates before creating renderer pools. Allocate systems once per distinct chain, not per renderer. Validate descriptors through ParticleSimulation.create or validateParticleDescriptor before returning plan. Test F01 graph -> analysis/expansion -> compiler -> exact tick0/59/60 particle counts, changed burst/size/lifetime, root transforms, disabled emitter/modifier/renderer/provider, sharing, group equivalence, unsupported field diagnostic, no input mutation.
