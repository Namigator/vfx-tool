# Performance evidence — 2026-09-29 (T37, WP25)

Environment: Windows 11, Chrome 152.0.7977.130 (in-app browser pane), GPU "ANGLE (NVIDIA GeForce RTX 2060 SUPER, Direct3D11)", 12 logical cores, DPR 1.
Method: `capture.html?bench=1&profile=balanced` in a 1920×1080 frame; every 6th tick is drawn synchronously three times (median kept) with `PreviewViewport.measureFrame()` (upload + composer render + gl.finish). requestAnimationFrame-based FPS was rejected: the pane throttles rAF to ~1 Hz when not focused, which produced meaningless 2–4 fps numbers.
